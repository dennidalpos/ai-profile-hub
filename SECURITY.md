# Security policy

Report security vulnerabilities through the [private GitHub reporting form](https://github.com/dennidalpos/ai-profile-hub/security/advisories/new). The form requires the repository's private vulnerability reporting feature. If the form is unavailable, open an issue asking for a private contact and omit vulnerability details.

Include the affected commit or version, client and operating system, impact, and steps using synthetic data. Keep credentials, profile databases and session directories private.

For ordinary bugs, use [GitHub Issues](https://github.com/dennidalpos/ai-profile-hub/issues).
